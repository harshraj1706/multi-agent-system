CogniSynth: Autonomous Research Platform
=========================================

REPOSITORY LAYOUT:
-----------------
multi_agent_system/
│
├── agent.py              # GeminiChatModel adapter, Agent definitions, Writer & Reviewer chains
├── pipeline.py           # Multi-agent streaming pipeline (Supervisor coordination & event dispatch)
├── tool.py               # Web search (Tavily) & Content extractor (Readability + BeautifulSoup)
├── api.py                # FastAPI backend with Server-Sent Events (SSE) streaming (/api/research)
├── app.py                # Streamlit premium real-time intelligence dashboard
├── test.py               # Automated smoke test suite
├── requirements.txt      # Python dependencies
├── .env                  # Environment variables & API credentials
├── running.txt           # Deployment instructions & configuration reference
└── README.md             # Platform documentation & architectural specifications
